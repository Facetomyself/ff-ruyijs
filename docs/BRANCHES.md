# Branches

The branch rules and the current snapshot live in [branching.md](branching.md). The Chinese copy is [branching.zh-CN.md](branching.zh-CN.md).

This file used to be a SHA ledger that had to be copied onto every `origin` branch. That ledger is retired. Update [branching.md](branching.md) when a branch's role changes. Do not update it just because a pointer fast-forwarded, and do not push a map commit onto every other branch.
